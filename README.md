## 📋 Descrição
 Sistema desenvolvido em Python que simula o monitoramento do nível de água de um reservatório. Exibe mensagens de alerta coloridas conforme o nível detectado, facilitando a identificação rápida da situação. Utiliza a biblioteca colorama para exibição de cores no terminal.
 ## 🎯 Níveis de Alerta
 | Nível | Situação | Cor |
 |-------|----------|-----|
 | 1 | Muito baixo — CRÍTICO | 🔴 Vermelho |
 | 2 | Baixo — Atenção | 🟡 Amarelo |
 | 3 | Médio — Situação normal | 🟢 Verde |
 | 4 | Alto — Fique atento | 🔵 Ciano |
 | 5 | Muito alto — Verificar transbordamento | 🔵 Azul |
 ## 🚀 Como executar
 1. Instale a biblioteca: pip install colorama
 2. Execute o arquivo: python reservatorio.py
